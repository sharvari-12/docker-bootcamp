pwd	- Print Working Directory — shows the full path of the directory you are currently in.

ls - List shows the files and folders in the current directory.

cd - Change Directory moves you from one directory/folder to another.

mkdir - Make Directory creates a new directory/folder.

touch - Creates a new empty file. If the file already exists, it updates its timestamp.

cp - Copy copies a file or directory to another location.

mv - Move moves a file/directory to another location. It can also be used to rename files.

rm - Remove deletes files or directories. Be careful because deleted files may not be recoverable.

rmdir - Remove Directory deletes an empty directory.
